# 用户页面操作指引录入（Record Step）功能需求文档

## 1. 目标

提供一个控制面板，用于录入“用户操作指引步骤”。  
录入过程由用户驱动页面操作，系统负责在指定时机采集步骤信息并允许编辑步骤文案。

## 2. 录入状态与按钮禁用规则

### 2.1 初始状态（未开始录入）
- 可用：`页面地址输入框`、`开始录入`
- 禁用：`拾取当前步骤`、`完成当前步骤`、`结束录制`、`导出`

### 2.2 录入准备状态（点击开始录入后）
- 行为：
  - 校验输入地址
  - Playwright 打开输入页面
  - 进入“录入准备”
- 可用：`拾取当前步骤`、`结束录制`、`新增自建步骤`
- 禁用：`开始录入`（避免重复启动）、`导出`

### 2.3 正在拾取步骤状态（点击拾取当前步骤后）
- 行为：
  - 仅监听“下一次用户点击”
  - 用户在打开页面点击后，立即采集该步信息
- 可用：`完成当前步骤`、`取消当前拾取（可选）`
- 禁用：`拾取当前步骤`（避免重复监听）、`开始录入`

### 2.4 当前步骤编辑状态（采集完成后）
- 可用：`主标题`、`副标题`编辑、`完成当前步骤`
- 规则：
  - 点击`完成当前步骤`后，该步录制结束并落入步骤列表
  - 完成后回到“录入准备状态”，可继续下一步

### 2.5 录制结束状态
- 行为：点击`结束录制`
- 可用：`步骤预览`、`导出`
- 禁用：`拾取当前步骤`、`完成当前步骤`

## 3. 录制步骤方案（按业务流程）

### 3.1 第 1 步：开始录入
- 用户点击`开始录入`
- Playwright 打开输入页面

### 3.2 第 2 步：拾取当前步骤
- 用户点击`拾取当前步骤`
- 系统监听用户“下一次”页面点击
- 当用户在打开页面点击元素时，开始采集页面信息：
  - 页面 URL
  - 页面元素信息（当前版本先采集 DOM 信息）

### 3.3 第 3 步：编辑当前拾取步骤
- 控制面板提供当前步骤编辑：
  - `主标题`
  - `副标题`
- 用户点击`完成当前步骤`，该步骤结束

### 3.4 第 4 步：用户可编辑“自建步骤”
- 场景：用户希望下一步指向另一个页面功能
- 自建步骤可填写（示例）：
  - `页面地址`
  - `页面指引信息`
- 关键约束：
  - 自建步骤不触发 Playwright 自动跳转
  - 页面跳转只能由用户自己操作完成
  - 目标是保证步骤连续性由用户行为决定，而不是系统强制跳转

### 3.5 第 5 步：继续录制
- 重复执行第 2 步（拾取下一步）

### 3.6 第 6 步：结束录制
- 用户点击`结束录制`
- 可预览全部步骤信息
- 可执行导出（如 JSON）

## 4. 步骤数据要求（当前版本）

每个录制步骤至少包含：
- `stepIndex`：步骤序号
- `pageUrl`：采集时页面地址
- `elementDom`：被点击元素的 DOM 信息（当前先原样保留）
- `elementId`：元素唯一 ID（方案待后续确定，先保留占位字段）
- `mainTitle`：主标题（用户编辑）
- `subTitle`：副标题（用户编辑）
- `stepType`：`picked` 或 `custom`

自建步骤至少包含：
- `stepIndex`
- `stepType: custom`
- `targetPageUrl`（可选）
- `guideText`（页面指引信息）

## 5. 功能边界说明

- 本文档仅作为功能需求文档。
- 不包含排期、资源评估、技术排期等管理项。
- 元素唯一 ID 算法、回放引擎、跨端兼容为后续阶段再定。
